# 输出目录

按 `YYYY-MM-DD` 建立独立日期目录。每个日期目录包含当天选题、自动生产记录和成品。

```text
YYYY-MM-DD/
├── 当天选题.md
├── 自动生产记录.md
└── 成品/
    ├── 封面/
    │   ├── cover.json
    │   └── NN-标题.png
    ├── 图文/
    ├── 视频/
    └── 发布记录.md
```

日期目录不保存图片和视频副本，只记录根目录素材相对路径。已有日期目录不得覆盖。

图文封面由项目专属每日生产 Skill 读取 `视觉模板/cover-theme.json` 后渲染。视觉未确认时不得把候选图标记为成品。
