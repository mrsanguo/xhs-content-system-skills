# 视觉规范

## 状态

待确认。视觉确认前不得把自动生成封面标记为最终成品。

## 视觉来源

- 对标账号、截图或链接：待用户提供；
- 可借鉴的视觉规则：待分析；
- 禁止复制的元素：账号名、Logo、水印、人物、原文和独特构图。

## 生成方式

- 方式：待确认，可选 `external-skill` 或 `local-renderer`；
- 外部视觉 Skill：待确认；
- 无法生成时：停止并生成封面制作单，不静默降级。

## 三版测试

1. 摄影主导版；
2. 编辑排版版；
3. 品牌图形版。

## 机器可读配置

封面生成配置保存在 `视觉模板/cover-theme.json`。确认视觉后把其中的 `status` 改为 `confirmed`，同步视觉来源、生成方式、配色、字体、亮度、布局和安全边距。选择外部 Skill 时，每日生产调用该 Skill；选择本地模板时才运行项目本地渲染器。每日生产不得绕过未确认状态。
