# 项目智能体规则

## 读取顺序

开始工作前依次读取：`project.yaml`、`README.md`、`当前进度.md`、定位方案、内容方案、视觉规范、最近 14 天输出。每日生产时再读取 `project.yaml` 中 `daily_producer.skill_path` 指向的项目专属 Skill。

## 事实与决策

- 当前对话中用户最新明确指令优先。
- 不编造经历、案例、数据、咨询、收入和效果。
- 未确认信息写“待确认”，不得擅自补全。
- 定位、产品、价格、公开边界和视觉体系的调整必须先确认。

## 内容生产

- 每条只讲一个核心观点，只有一个主要行动指令。
- 图文生成完整正文和封面；视频生成口播、镜头、字幕重点和发布配文，不伪造真人视频。
- 使用真实素材；根目录素材不移动、不删除、不修改。
- 日期目录只记录素材相对路径，不复制图片和视频。

## 安全边界

- 所有新内容默认“待审核”。
- 不自动发布，不登录平台，不发送真实私信或评论。
- 不覆盖已有日期目录和历史成品。
- 不公开未经确认的地址、价格、联系方式和隐私。

## 文件维护

- 新决定同步到 `project.yaml` 和对应方案。
- 已完成事项同步到 `当前进度.md`。
- 发布后补充 `成品/发布记录.md` 和 `数据复盘/发布数据.csv`。
- 项目专属每日生产 Skill 位于 `skills/{{DAILY_SKILL_NAME}}/`；不得改用其他项目的 Skill。
