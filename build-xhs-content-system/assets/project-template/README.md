# {{PROJECT_NAME}}

创建日期：{{CREATED_DATE}}

这是一个面向“{{INDUSTRY}}”的{{PLATFORM}}内容项目。项目目标、账号定位和产品信息以 `project.yaml` 为机器读取主入口，以各 Markdown 方案为详细说明。

## 智能体工作顺序

1. 读取 `AGENTS.md`；
2. 读取 `project.yaml`；
3. 读取 `当前进度.md`；
4. 根据任务读取定位、包装、内容、视觉或话术文件；
5. 生产内容时读取最近 14 天输出和 `素材索引.md`；
6. 所有成品保留“待审核”，不自动发布。

## 主要入口

- `账号定位与商业方案.md`：定位、受众、产品和转化路径；
- `账号包装方案.md`：名称、简介、头像和置顶内容；
- `内容策划方案.md`：栏目、选题和 14 天计划；
- `视觉规范.md`：已确认的封面和画面规则；
- `私信与评论话术.md`：公开回复和私信边界；
- `当前进度.md`：已完成、待确认和下一步；
- `输出/`：每天的待审核内容与发布记录。

## 素材原则

所有图片、视频和参考资料保存在根目录素材库。日期目录不复制原始素材，只记录相对路径和用途。

## 每日生产入口

在项目根目录运行：

```bash
skills/{{DAILY_SKILL_NAME}}/scripts/run_daily.sh --project-root . --date YYYY-MM-DD
```

增加 `--dry-run` 只检查运行条件。脚本只生成待审核内容，不自动发布。
