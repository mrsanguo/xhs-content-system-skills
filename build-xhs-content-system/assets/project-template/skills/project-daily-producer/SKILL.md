# 项目每日内容生产

## 定位

这是通用模板生成的项目专属 Skill。行业、城市、受众、产品、案例、价格、行动指令和视觉参数只能从当前项目读取，不得使用其他项目的内容。

先从 `project.yaml` 读取 `daily_producer.skill_path`，记为 `<daily-skill-path>`。该路径必须指向本 Skill；不一致时停止并记录冲突。

## 读取

依次读取项目根目录的 `AGENTS.md`、`project.yaml`、`当前进度.md`、定位方案、内容方案、视觉规范、私信与评论话术、数据复盘、素材索引和最近 14 天输出。事实优先级为：用户最新明确指令、`project.yaml`、项目规则、方案、当前进度、历史输出。

## 生产

1. 确定目标日期并检查 `输出/YYYY-MM-DD/`；已有任何内容时停止，不覆盖也不补写。
2. 汇总最近 14 天已经使用的主题、标题、形式、素材和行动指令。
3. 根据最新真实评论、私信与复盘、14 天计划和历史去重选择一条内容。数据不足时只调整选题角度，不擅自改变定位、产品、价格或目标用户。
4. 运行 `python3 <daily-skill-path>/scripts/build_material_index.py --project-root .`，从根目录素材库选择真实素材，只记录相对路径和用途。
5. 运行 `python3 <daily-skill-path>/scripts/create_daily_package.py --project-root . --date YYYY-MM-DD --format 图文|视频` 创建日期内容包。
6. 图文生成完整正文、5—8 个话题和一个行动指令；视频生成口播、镜头、字幕重点、发布配文和补拍要求，不伪造真人视频。
7. 从 `project.yaml` 的 `visual_generation` 和 `视觉模板/cover-theme.json` 读取封面方式，两处必须一致且状态已确认：
   - `external-skill`：完整读取 `generator_skill` 指定的视觉 Skill，按“小红书竖版 3:4”生成封面；有对标时使用参考图流程，没有对标时直接让该 Skill 按标题、内容和账号定位设计生成。保存 PNG 后写入 `cover.json`，注明 `generator: external-skill` 与 Skill 名称；
   - `local-renderer`：写入 `cover.json`，注明 `generator: local-renderer`，再运行 `<daily-skill-path>/scripts/render_cover.sh --spec 输出/YYYY-MM-DD/成品/封面/cover.json`；
   - 未确认、Skill 不可用或工具不可用：停止出图，生成 `成品/封面/封面制作单.md` 说明标题、素材、比例和已确认风格，不得静默换成本地模板。
8. 补全当天选题、自动生产记录和发布记录，明确引用的原始素材、去重依据和“未自动发布”。
9. 运行 `python3 <daily-skill-path>/scripts/validate_daily_output.py --project-root . --date YYYY-MM-DD`，将状态保留为“待审核”。

## 选题原则

1. 最新真实反馈和当前验证问题；
2. 尚未覆盖的内容计划；
3. 项目内可验证的经历、案例、作品与过程；
4. 目标用户反复出现的问题；
5. 产品解释与行动引导。

避免连续两条使用同一开头、核心结论、内容形式或封面素材。每条只讲一个核心观点，只有一个主要行动指令。

## 禁止

- 不编造事实、案例、数据或反馈；
- 不覆盖历史内容；
- 不复制根目录素材；
- 不自动发布、评论或私信；
- 不擅自改变定位、产品、价格和视觉体系；
- 不把模板示例、其他行业或其他项目的信息写入当前内容；
- 不在标题、图片或正文公开未经确认的隐私与商业信息。

## 完成标准

- 当天选题、自动生产记录、内容成品和发布记录齐全；
- 图文标题不超过 20 个字符；本地模板封面为 1080×1440 PNG，外部 Skill 封面必须为清晰的 3:4 竖版；
- 视频稿包含口播、镜头、字幕、配文和补拍要求；
- 只引用根目录真实素材，并记录相对路径；
- 状态为“待审核”，发布记录明确“未自动发布”；
- 校验脚本通过。
