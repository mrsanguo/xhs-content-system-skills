# 数据复盘与调整

## 输入

读取发布记录、曝光、点击、点赞、收藏、评论、私信、有效咨询、到店或成交，以及真实评论和私信内容。

## 每周复盘

区分三层：

1. 事实：实际发布和数据；
2. 推断：可能有效或无效的原因；
3. 动作：下周继续、停止或测试什么。

复盘标题、开头、内容主题、形式、封面、行动指令和咨询质量。没有足够样本时只做小测试，不宣布定位失败。

平台拿不到逐篇曝光或观看时，不把缺失值写成 0，也不为了补齐表格反复采集。至少记录点赞、收藏、评论、私信、继续沟通、符合条件、到访和付费。

区分转化阶段：

- 原始咨询：评论或私信表达兴趣；
- 有效咨询：回复筛选问题后仍继续沟通，能够确认方向和需求；
- 到访或深度沟通：已经发生，不用预约代替实际结果；
- 付费或成交：已经付款，不用口头意向代替。

老号重新定位时，只把新定位后的内容作为当前样本，并把历史受众标签视为可能影响因素，不能直接当作当前内容失败的原因。

## 修改权限

- 选题角度、标题和表达方式可以根据数据微调；
- 栏目比例、发布频率和视觉细节需要写入进度；
- 定位、产品、价格、目标用户和公开边界必须先让用户确认；
- 不把相关性当作因果，不承诺下一条一定增长。
