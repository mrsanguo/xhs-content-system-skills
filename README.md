# 小红书内容系统 Skills

这是一套把“小红书账号定位、内容规划、视觉确认、每日生产和复盘”放进同一个项目文件夹的开源 Skill。

它适合个人创业者、本地门店、专业服务者、知识 IP 和小团队。它负责生成待审核内容，不会替你登录小红书、公开发布或发送私信。

## 这套系统怎样组成

它看起来有三层，实际只需要安装一个 Skill。

1. `build-xhs-content-system` 是项目搭建器，负责从 0 到 1 梳理业务、定位、账号包装、内容栏目和视觉方向。
2. 项目搭建器内部带有通用每日生产母版，不写死行业、城市、产品和行动指令。
3. 每次建立新项目时，系统会生成一个只服务于该项目的每日生产 Skill。

这样做可以避免不同账号的定位、素材和文案互相串用。

## 能做什么

- 新建或接管一个小红书内容项目。
- 梳理受众、产品、信任理由和转化路径。
- 生成账号包装、内容栏目、基础选题和前 14 天计划。
- 优先参考用户提供的视觉对标，再确认封面风格和生成方式。
- 为每个项目生成独立的每日生产 Skill。
- 按日期生成图文或视频待审核内容包。
- 统一引用根目录图片和视频素材，不在每日目录重复复制。
- 校验目录、封面尺寸、发布状态和项目隔离。
- 根据发布数据、评论和私信做复盘。

## 安装

### Codex 一键安装

仓库发布后运行下面的命令。

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo mrsanguo/xhs-content-system-skills \
  --path build-xhs-content-system
```

安装完成后重新打开一个 Codex 任务，让 Skill 出现在可用 Skills 列表中。

### 手动安装

把 `build-xhs-content-system` 文件夹复制到智能工具的 Skills 目录。工具无法自动识别 Skill 时，可以让它完整读取 `SKILL.md`，再按里面的步骤执行。

本地封面渲染需要 Python 3 和 Pillow。

```bash
python3 -m pip install Pillow
```

## 最小使用示例

在 Codex 中直接说。

```text
使用 $build-xhs-content-system，帮我从 0 到 1 搭建一个宠物营养咨询的小红书内容项目。
项目放在我指定的文件夹。先完成定位和视觉确认，不要自动发布。
```

搭建完成后可以继续说。

```text
使用这个项目生成的每日生产 Skill，准备明天的小红书待审核内容。
```

完整教程见 [中文使用指南](docs/使用指南.md)。

## 视觉说明

系统不会直接把默认模板当成正式封面。正常流程会先让用户提供一至三个对标账号、截图或封面。有对标时交给封面 Skill 参考，没有对标时直接让封面 Skill 根据内容设计生成；只有用户明确要求固定模板时，才使用本地模板。

项目默认模板带有测试占位标记。没有完成视觉确认，自动生产会停止。

## 安全边界

- 所有内容默认处于待审核状态。
- 不自动发布小红书。
- 不发送真实私信和评论。
- 不覆盖已有日期目录和原始素材。
- 不公开未经确认的地址、价格、联系方式和隐私。
- 不承诺流量、成交和收入结果。
